📌 项目简介

本项目为《计算机组成原理》课程设计，实现了一台基于 VHDL 的嵌入式 CISC（Complex Instruction Set Computer）模型计算机。

模型机采用微程序控制方式，通过设计 CPU 数据通路、指令系统、微程序控制器、ALU、寄存器、ROM、PSW 等核心部件，构建完整的模型计算机，并通过 EDA 工具进行功能仿真。

项目最终实现：

输入 5 个整数，寻找其中最大的正整数，并输出该整数的相反数。

整个设计覆盖了从指令系统设计 → 微指令设计 → VHDL 硬件实现 → ROM 程序加载 → EDA 功能仿真的完整流程。

🧠 微程序控制器

模型机采用微程序控制器实现 CPU 的控制信号生成。

微指令主要由：

┌──────────────┬────────────┬──────────────────┐
│   下址字段    │   判别字段   │   微操作控制字段   │
└──────────────┴────────────┴──────────────────┘

组成。

机器指令进入指令寄存器后，根据操作码找到对应的微程序入口地址。

随后：

机器指令
   │
   ▼
指令译码
   │
   ▼
微程序入口
   │
   ▼
控制存储器
   │
   ▼
微指令
   │
   ├───────────────▶ 微操作控制信号
   │
   ▼
条件判断
   │
   ▼
微地址选择
   │
   ▼
下一条微指令

通过这种方式实现机器指令到具体硬件控制信号之间的映射。

📋 指令系统

模型机设计了以下主要指令：

操作码	指令	功能
0001	IN1 Rd	输入一个整数
0010	MOV Rd, im	立即数送入寄存器
0011	CMP Rs, Rd	比较两个寄存器
0100	JA addr	大于则跳转
0101	JBE addr	小于等于则跳转
0110	ADD Rs, Rd	加法
0111	NEG Rd	求相反数
1000	JMP addr	无条件跳转
1001	OUT1 Rs	输出寄存器
1010	DEC Rd	寄存器自减

其中：

NEG

NEG Rd

执行：

Rd ← -Rd

该指令用于完成题目要求的求相反数操作。

DEC

DEC Rd

执行：

Rd ← Rd - 1

用于实现循环计数。

🔧 核心 VHDL 模块

ALU.vhd

实现模型机的算术逻辑运算，包括：

* 加法
* 减法
* 求相反数
* 自减
* AND
* OR
* 数据传送

⸻

PC.vhd

实现程序计数器：

PC ← Address

以及：

PC ← PC + 1

⸻

ROM.vhd

用于存储模型机运行的机器程序。

ROM 中保存经过编码后的机器指令，由 CPU 根据 PC 地址读取。

⸻

CONTROM.vhd

用于保存微程序控制信息，根据当前微地址产生对应的微操作控制信号。

⸻

CONVERT.vhd

负责将 16 位机器指令拆分为：

┌────────┬──────────────┬────────────┐
│   OP   │ 寄存器/控制字段 │ 地址/立即数字段 │
└────────┴──────────────┴────────────┘

⸻

PSW.vhd

保存 ALU 运算产生的状态信息，为 JA、JBE 等条件跳转指令提供判断依据。

🐛 调试记录

在模型机仿真过程中，曾出现指令位置偏移的问题。

经过分析发现，不同数据的运算过程存在一定的时序差异，导致输入指令与模型机执行过程之间出现不同步。

通过：

* 观察仿真波形
* 分析指令执行周期
* 定位 IN1 指令位置
* 分次进行数据输入
* 检查控制信号

最终定位并解决了相关问题。

这个过程也体现了硬件设计中时序分析与波形调试的重要性。
