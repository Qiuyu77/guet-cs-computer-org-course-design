# 桂林电子科技大学计算机组成原理课程设计 B 题

**Embedded CISC Model Computer**

基于 VHDL 的嵌入式 CISC 模型计算机设计与功能仿真。

---

## 项目简介

本项目为《计算机组成原理》课程设计，实现了一台基于 VHDL 的嵌入式 CISC（Complex Instruction Set Computer）模型计算机。

模型机采用微程序控制方式，通过设计 CPU 数据通路、指令系统、微程序控制器、ALU、寄存器、ROM、PSW 等核心部件，构建完整的模型计算机，并通过 EDA 工具进行功能仿真。

项目最终实现：

> 输入 5 个整数，寻找其中最大的正整数，并输出该整数的相反数。

整个设计覆盖从指令系统设计、微指令设计、VHDL 硬件实现、ROM 程序加载到 EDA 功能仿真的完整流程。

## 系统架构

本模型计算机采用 **嵌入式 CISC 结构**。CPU 采用三数据总线结构，并使用微程序控制器实现指令的译码与执行。系统整体由 CPU、存储器、总线、寄存器、ALU 以及微程序控制器等部分组成。

### 整体结构

系统采用指令存储器与数据存储器相对独立的结构，并分别设置指令总线和数据总线。

| 模块 | 功能 |
| --- | --- |
| PC | 程序计数器 |
| IR | 指令寄存器 |
| AR | 地址寄存器 |
| R0 ~ R3 | 通用寄存器 |
| ALU | 算术逻辑运算 |
| PSW | 保存运算状态标志 |
| ROM | 存储机器指令 |
| RAM | 数据存储 |
| μAR | 微地址寄存器 |
| CONTROM | 微程序控制存储器 |
| MUX | 微地址选择 |
| CONVERT | 指令字段解析 |

主要数据通路关系：

- 指令存储器经 **IBUS** 向 CPU 提供机器指令。
- 微程序控制器根据当前微地址发出微操作控制信号，控制 PC、IR、AR、R0~R3、PSW 与 ALU。
- CPU 经 **DBUS** 与数据存储器交换数据。

## 微程序控制器

模型机采用微程序控制器实现 CPU 的控制信号生成。

微指令主要由以下字段组成：

| 下址字段 | 判别字段 | 微操作控制字段 |
| --- | --- | --- |

机器指令进入指令寄存器后，根据操作码找到对应的微程序入口地址。执行过程为：

1. 机器指令进入指令寄存器。
2. 指令译码，得到微程序入口。
3. 控制存储器按微地址读出微指令。
4. 微操作控制字段产生硬件控制信号。
5. 根据判别字段与状态标志进行条件判断。
6. 微地址选择电路形成下一条微指令地址。

通过这种方式，实现机器指令到具体硬件控制信号之间的映射。

## 指令系统

模型机设计了以下主要指令：

| 操作码 | 指令 | 功能 |
| --- | --- | --- |
| 0001 | `IN1 Rd` | 输入一个整数 |
| 0010 | `MOV Rd, im` | 立即数送入寄存器 |
| 0011 | `CMP Rs, Rd` | 比较两个寄存器 |
| 0100 | `JA addr` | 大于则跳转 |
| 0101 | `JBE addr` | 小于等于则跳转 |
| 0110 | `ADD Rs, Rd` | 加法 |
| 0111 | `NEG Rd` | 求相反数 |
| 1000 | `JMP addr` | 无条件跳转 |
| 1001 | `OUT1 Rs` | 输出寄存器 |
| 1010 | `DEC Rd` | 寄存器自减 |

### NEG

```text
NEG Rd
```

执行：

```text
Rd ← -Rd
```

该指令用于完成题目要求的求相反数操作。

### DEC

```text
DEC Rd
```

执行：

```text
Rd ← Rd - 1
```

用于实现循环计数。

## 指令执行流程

模型机采用基本的 **取指 → 译码 → 执行** 流程。

### 取指

1. PC 给出指令地址。
2. ROM 读出机器指令。
3. 指令写入 IR。
4. 对 IR 中的操作码进行译码。

### 执行

根据不同指令进入对应的执行周期：

| 指令 | 执行内容 |
| --- | --- |
| IN1 | 输入 |
| MOV | 数据传送 |
| CMP | 比较 |
| JA | 条件跳转（大于） |
| JBE | 条件跳转（小于等于） |
| ADD | 算术运算 |
| NEG | 求相反数 |
| JMP | 无条件跳转 |
| OUT1 | 输出 |
| DEC | 循环控制 |

---

## 程序执行逻辑

整体程序完成“输入 5 个整数，求最大正整数的相反数并输出”：

1. 初始化寄存器。
2. 设置循环次数为 5。
3. 输入一个整数。
4. 判断该数是否为正数。
   - 若不是正数，跳过比较。
   - 若是正数，与当前最大值比较。
   - 若更大，则更新最大值。
5. 循环执行 5 次。
6. 对最大值执行 `NEG`。
7. 执行 `OUT1` 输出结果。
8. 程序结束。

## 核心 VHDL 模块

### ALU.vhd

实现模型机的算术逻辑运算，包括：

- 加法
- 减法
- 求相反数
- 自减
- AND
- OR
- 数据传送

### PC.vhd

实现程序计数器：

```text
PC ← Address
PC ← PC + 1
```

### ROM.vhd

用于存储模型机运行的机器程序。ROM 中保存经过编码后的机器指令，由 CPU 根据 PC 地址读取。

### CONTROM.vhd

用于保存微程序控制信息，根据当前微地址产生对应的微操作控制信号。

### CONVERT.vhd

负责将 16 位机器指令拆分为：

| 操作码 OP | 寄存器 / 控制字段 | 地址 / 立即数字段 |
| --- | --- | --- |

### PSW.vhd

保存 ALU 运算产生的状态信息，为 `JA`、`JBE` 等条件跳转指令提供判断依据。

## 功能仿真

使用以下数据进行功能验证：

```text
5, -27, 7, 9, 3
```

对应的 8 位补码：

| 十进制 | 8 位补码（十六进制） |
| --- | --- |
| 5 | 05 |
| -27 | E5 |
| 7 | 07 |
| 9 | 09 |
| 3 | 03 |

最大正整数为 **9**。

执行 `NEG` 后得到 **-9**。

8 位补码：

```text
11110111
```

十六进制：

```text
F7
```

因此最终输出应为 **F7**。功能仿真结果与理论结果一致，验证了模型机的基本功能。

---

## 仿真结果

典型测试流程：

1. 输入数据：`05`、`E5`、`07`、`09`、`03`。
2. 求得最大正整数：`09`。
3. 执行 `NEG`。
4. 得到结果：`F7`。
5. 输出 `F7`。

## 调试记录

在模型机仿真过程中，曾出现指令位置偏移的问题。

经过分析发现，不同数据的运算过程存在一定的时序差异，导致输入指令与模型机执行过程之间出现不同步。

调试时采取的方法：

- 观察仿真波形
- 分析指令执行周期
- 定位 `IN1` 指令位置
- 分次进行数据输入
- 检查控制信号

最终定位并解决了相关问题。这个过程也体现了硬件设计中时序分析与波形调试的重要性。
