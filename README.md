📖 项目简介

本项目是《计算机组成原理》课程设计项目，实现了一台嵌入式 CISC 模型计算机。

模型机采用三数据总线结构 CPU和微程序控制器，通过 VHDL 对 CPU、ALU、寄存器、程序计数器、指令寄存器、RAM、ROM、PSW 以及微程序控制器等模块进行设计，并将各模块连接形成完整的模型计算机。

本项目最终实现的功能为：

任意输入 5 个整数，计算其中最大的正整数，并输出该数的相反数。

例如：

输入：
5
-27
7
9
3
最大正整数：
9
输出：
-9

在 8 位定点整数补码表示下，-9 对应的补码为：

11110111

即十六进制：

F7

课程设计报告中的功能仿真结果也验证了该设计能够正确完成上述功能。

📋 指令系统

本模型机设计了以下机器指令：

指令	操作	功能
IN1 Rd	输入	输入一个整数到寄存器 Rd
MOV Rd, im	立即数传送	将立即数送入寄存器
CMP Rs, Rd	比较	比较两个寄存器并设置状态标志
JA addr	条件跳转	大于则跳转
JBE addr	条件跳转	小于等于则跳转
ADD Rs, Rd	加法	Rd = Rs + Rd
NEG Rd	求相反数	Rd = -Rd
JMP addr	无条件跳转	跳转到指定地址
OUT1 Rs	输出	输出寄存器内容
DEC Rd	自减	Rd = Rd - 1

其中 NEG 为本课程设计中专门设计的求相反数指令，DEC 用于辅助实现五次输入和循环控制。

💻 汇编程序

本项目使用自定义指令集编写汇编程序，实现：

输入 5 个整数
      ↓
判断是否为正数
      ↓
寻找最大正整数
      ↓
对最大正整数执行 NEG
      ↓
OUT1 输出

程序核心逻辑可以概括为：

MOV R1, 0
MOV R3, 0
MOV R2, 5
MOV R0, FF
; 循环输入并寻找最大正整数
...
NEG R0
OUT1 R0

课程设计报告中给出了完整的汇编语言程序以及对应的二进制、十六进制机器指令。

🛠️ VHDL 模块

项目主要使用 VHDL 完成硬件模块设计。

主要模块包括：

├── WCXRKCZ.vhd       # 微程序入口地址查找
├── TJPBCS.vhd        # 地址转移判断逻辑
├── MUX4_1_W.vhd      # 4选1多路选择器
├── UAR.vhd           # 微地址寄存器
├── CONTROM.vhd       # 控制存储器
├── ALU.vhd           # 算术逻辑单元
├── PC.vhd             # 程序计数器
├── ROM.vhd            # 指令 ROM
├── IR.vhd             # 指令寄存器
├── PSW.vhd            # 程序状态字寄存器
└── CONVERT.vhd        # 指令译码模块

其中：

* ALU.vhd 实现加法、减法、求补码、减一、逻辑与、逻辑或以及数据直通等运算；
* PC.vhd 实现程序计数器加载和 PC+1；
* ROM.vhd 存储模型机运行所需的机器程序；
* CONTROM.vhd 存储微指令控制信息；
* PSW.vhd 保存运算产生的状态标志；
* CONVERT.vhd 完成机器指令字段拆分。

🐛 调试与问题分析

在功能仿真过程中曾出现指令偏移问题。

一次性输入 5 个数据时，IN1 指令的位置发生偏移，导致部分情况下计算结果不正确。

经过分析发现：

正数和负数的运算步骤存在差异，负数计算所需要的时间更长，从而造成输入指令与执行时序之间的不匹配。

最终通过分次输入、逐次仿真的方式确定取数指令的位置，并根据波形进行时序调试，最终得到正确的仿真结果。
